## 2024-05-19 - [Pygame Surface Creation Optimization]
**Learning:** For Pygame + OpenCV video frame rendering, `pygame.image.frombytes` is more efficient and safer than `np.transpose` followed by `pygame.surfarray.make_surface`. Doing `pygame.surfarray.make_surface` on a local numpy array can cause a use-after-free vulnerability when the array is garbage collected (because it shares memory). In addition, resizing a frame with `cv2.resize` *before* converting it from BGR to RGB reduces the number of pixels processed during color conversion, thus saving processing time.
**Action:** When dealing with Pygame surface conversion from ndarray frames (like OpenCV), use `cv2.resize` directly on the BGR ndarray, then use `cv2.cvtColor`, and finally copy memory explicitly to the surface via `pygame.image.frombytes(array.tobytes(), ...)` rather than using `pygame.surfarray.make_surface()`.
