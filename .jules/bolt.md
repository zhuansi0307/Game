## 2025-02-14 - Pygame Video Rendering Optimization
**Learning:** Pygame `surfarray.make_surface` coupled with `np.transpose` creates significant overhead during video rendering, dropping frame rate noticeably. Using `cv2.resize` on the array directly instead of `pygame.transform.smoothscale`, and mapping the bytes directly to a Pygame Surface using `pygame.image.frombuffer` improves frame processing time by an order of magnitude. Note that `frombuffer` expects a `(width, height)` size tuple while OpenCV/NumPy use `(height, width, channels)`.
**Action:** When handling video playback with Pygame and OpenCV, avoid `surfarray.make_surface` and `np.transpose`. Always use `cv2.resize` and `pygame.image.frombuffer(frame.data, (width, height), 'RGB')` (after ensuring the array is contiguous) to maximize performance.
