## 2024-05-30 - [Optimize Pygame Surface Creation]
**Learning:** For Pygame + OpenCV video frame rendering optimization, `pygame.image.frombuffer` if the source numpy array is a local variable, as it shares memory and causes a use-after-free vulnerability when the array is garbage collected. Instead, use `pygame.image.frombytes(array.tobytes(), (frame.shape[1], frame.shape[0]), 'RGB')` to safely copy the memory. This approach avoids expensive `np.transpose` and `pygame.surfarray.make_surface` operations. Additionally, prefer using `cv2.resize` directly on the ndarray (before color conversion) rather than `pygame.transform.smoothscale` for efficient frame resizing.
**Action:** Use `cv2.resize` before color conversion, and use `pygame.image.frombytes` for converting RGB frames to surfaces.
