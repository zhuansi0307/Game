## 2024-05-30 - [Optimize Video Frame Conversion to Pygame Surface]
**Learning:** In Pygame, converting OpenCV frames (which are NumPy arrays) into Pygame Surfaces using `np.transpose` and `pygame.surfarray.make_surface` is CPU-intensive. A zero-copy approach using `pygame.image.frombuffer` avoids the expensive array transposition step. Furthermore, performing scaling directly on the numpy array using OpenCV's `cv2.resize` (prior to color conversion) is generally faster than converting to a Surface and then using `pygame.transform.smoothscale`.
**Action:** Replace `np.transpose` and `pygame.surfarray.make_surface` with `pygame.image.frombuffer(frame.data, (width, height), 'RGB')`. If scaling is necessary, apply `cv2.resize` on the raw OpenCV frame first, then convert color to RGB, ensure it is contiguous, and use `frombuffer`.
