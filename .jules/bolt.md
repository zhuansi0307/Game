## 2025-08-08 - [Optimize Pygame + OpenCV video frame rendering]
**Learning:** In Pygame, converting video frames to surfaces is often a bottleneck due to `np.transpose` and `pygame.surfarray.make_surface()`. `pygame.image.frombuffer` on `rgb.data` alongside contiguous memory layout (`np.ascontiguousarray`) is a zero-copy approach which is far more efficient. Additionally, `cv2.resize` acting directly on BGR frames *before* color conversion is significantly faster than resizing the converted RGB frames or using `pygame.transform.smoothscale`.
**Action:** Use `pygame.image.frombuffer` directly with the frame buffer `data` and proper shape tuple for efficient Pygame surfaces mapping from ndarrays. Apply scaling via `cv2.resize` strictly on the rawest possible frame stage (e.g. BGR before RGB conversion).
