## 2024-05-24 - Pygame + OpenCV Zero-Copy Surface Rendering Optimization
**Learning:** For rendering OpenCV frames (BGR format, ndarray) into Pygame Surfaces, the traditional pipeline of converting color formats (`cv2.cvtColor`), transposing array dimensions (`np.transpose`), and constructing surfaces via `pygame.surfarray.make_surface` is highly unoptimized and CPU intensive. Pygame 2.x supports directly reading BGR memory buffers!
**Action:** When bridging OpenCV to Pygame, completely drop color conversion and transposing. Instead, directly resize the original BGR frame, ensure it is contiguous in memory (`np.ascontiguousarray`), and construct the surface via `pygame.image.frombuffer(frame.data, size, 'BGR')`. This zero-copy approach eliminates massive computational overheads.
