## 2024-05-18 - AssetManager JSON Parsing Bottleneck
**Learning:** Found a performance bottleneck where JSON data (such as `scenes.json`, `tasks.json`, etc.) is re-parsed from the disk every single time `load_scenes()`, `load_tasks()`, and other related methods are called in `AssetManager`. The engine makes many redundant calls to these loading methods on a frequent basis during scene transitions and logic checks, resulting in unnecessary I/O and CPU overhead.
**Action:** Applied instance-level caching with `self.json_cache` to the `_load_json` function in `AssetManager`, combined with `copy.deepcopy()` to prevent mutable state corruption. This guarantees that each JSON file is parsed only once across the application lifecycle, vastly improving backend state parsing speed without risking memory leaks or shared state mutation.
